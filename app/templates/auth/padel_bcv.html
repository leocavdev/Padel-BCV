FAQ
{# 1 – Réserver un match #}
Comment réserver un match ?
  1. Ouvrez l'onglet Matchs.
  2. Consultez les matchs disponibles (Ouvert = places libres).
  3. Appuyez sur un match pour voir ses détails : date, lieu, niveau requis, prix.
  4. Si votre niveau est suffisant, appuyez sur Rejoindre.
  5. Choisissez votre mode de paiement : solde (déduction immédiate) ou TWINT (si le bouton ne fonctionne pas, il est possible de scanner le QR code directement via l'application TWINT).

Dès que 4 joueurs sont inscrits, le match passe automatiquement à Complet.

{# 2 – Quitter un match #}
Comment quitter un match ?

Il n'est pas possible de quitter un match directement. Vous devez trouver un remplaçant :

  1. Ouvrez la page du match et appuyez sur Demander un remplacement.
  2. Sélectionnez un joueur dans la liste (niveau suffisant requis).
  3. Le joueur reçoit une notification et accepte ou refuse.
  4. S'il accepte et paie, vous êtes libéré du match et remboursé sur votre solde.

Tant que le remplacement n'est pas accepté, vous restez inscrit au match.

{# 3 – Payer un match #}
Comment payer un match ?

Lors de l'inscription, deux options s'offrent à vous :

  • Payer via le solde — le montant est déduit instantanément de votre portefeuille. C'est la méthode la plus rapide.
  • Payer via TWINT — un QR code s'affiche. Scannez-le avec votre application TWINT, puis appuyez sur J'ai payé dans l'application pour confirmer votre place.

Tant que le paiement n'est pas confirmé, votre inscription est en attente (En attente).

{# 4 – Le solde #}
Comment fonctionne le solde ?

Votre solde (onglet Solde) fonctionne comme un portefeuille prépayé :

  • Recharge — uniquement par un administrateur, après que vous ayez effectué un TWINT et transmis le reçu à un administrateur (Withawat ou Leonardo).
  • Débit — automatique lors du paiement d'un match (–X CHF).
  • Remboursement — si vous trouvez un remplaçant pour un match déjà payé, le montant vous est recrédité automatiquement.

Consultez l'historique complet de vos mouvements dans l'onglet Solde.

{# 5 – Niveau initial #}
Comment mon niveau initial est-il attribué ?

Votre niveau de départ est fixé par un administrateur lors de la création de votre compte, sur la base de votre expérience déclarée et/ou d'une évaluation sur le terrain.

Il est exprimé sur une échelle de 0 à 7 et détermine votre catégorie :

  • Débutant — 0.0 à 1.9
  • Intermédiaire — 2.0 à 3.9
  • Avancé — 4.0 à 5.9
  • Expert — 6.0 à 7.0

Si vous pensez que votre niveau est mal évalué, contactez un administrateur.

{# 6 – Impact des résultats #}
Comment les résultats impactent-ils mon niveau ?

Après chaque match complet et dont le résultat est validé :

  • Victoire → +0.05 point
  • Défaite → −0.05 point

Le niveau ne peut pas dépasser 7.0 ni descendre en dessous de 0.0. Votre catégorie est recalculée automatiquement à chaque mise à jour.

{# 7 – Soumettre un résultat #}
Comment soumettre le résultat d'un match ?

Le résultat est soumis de manière collaborative par les joueurs :

  1. Le jour du match (ou après), un joueur ouvre la page du match et appuie sur Proposer un résultat.
  2. Il assigne chaque joueur à une équipe (Équipe 1 ou Équipe 2) et indique l'équipe gagnante.
  3. Un joueur de l'équipe adverse doit ensuite confirmer le résultat.
  4. Une fois confirmé, les niveaux sont mis à jour automatiquement.

Si le résultat est contesté, la proposition est annulée et un nouveau résultat peut être soumis.

{# 8 – Niveau requis #}
Que signifie le niveau requis d'un match ?

Chaque match peut avoir un niveau minimum requis. Si votre catégorie est inférieure à ce niveau, vous ne pouvez pas vous inscrire.

Cela garantit des parties équilibrées et respectueuses du niveau de jeu de chacun. Votre niveau actuel est toujours visible sur votre Profil.
